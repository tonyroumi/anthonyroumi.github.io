Learning Stylistic Humanoid Motions

Reinforcement Learning · Imitation Learning

Code / Notes

This project explores learning to compose stylistic humanoid motions through reinforcement learning, drawing on ideas from Adversarial Motion Priors and DeepMimic. The goal is to learn task-driven behaviors guided by reference motions, while enabling transitions between learned skills.

Overview

A manifest defines which motion clips to sample from and their respective environment configuration. 

motions:
  walk_to_goal:
    file: data/locomotion/walk.npz
    sample_prob: 0.55
    amp: 2.0

    commands:
      goal_x: [-5.0, 5.0]
      goal_y: [-5.0, 5.0]

    zero_command_prob: 0.25

    rewards:
      progress:
        weight: 3.0
        scale: 30.0
      target_hit:
        weight: 1.0
        scale: 0.5

    termination:
      unhealthy:

  jump:
    file: data/jump/standing_broad_jump.npz
    sample_prob: 0.35
    trigger: binary_key_0
    amp: 0.0
    random_start: true

    rewards:
      heading_motion_tracking:
        weight: 20.0
        dof_scale: 0.5
        key_body_scale: 0.5
      action_rate_l2:
        weight: 0.5
        scale: 1.0
      joint_acc:
        weight: 0.1
        scale: 1.0e-4

    termination:
      unhealthy:
      deviation_from_motion:
        threshold: 3.0

The environment then produces motion specific commands, triggers, rewards, and terminations.

Episodes can initialize from any reference motion, execute triggers mid-episode, and transition back to steady-state behavior.
